# 🐍 Python
Idioma para darle órdenes a la compu, línea por línea. ← [[00 - Índice]]

| Concepto | Ejemplo | Qué es |
|---|---|---|
| Mostrar | `print("Hola")` | Escribe en pantalla |
| Variable | `edad = 30` | Cajita con nombre (`=` guarda, no compara) |
| Tipos | `5`, `3.5`, `"hola"`, `True` | int (entero), float (decimal), str (texto), bool (verdadero/falso) |
| Lista | `frutas = ["a","b"]` → `frutas[0]` | Fila de cajitas. **Se cuenta desde 0** |
| Diccionario | `{"nombre": "Ana"}` → `p["nombre"]` | Agenda: clave → valor |
| If | `if edad >= 18:` / `else:` | Decidir. **La sangría es obligatoria** |
| For | `for f in frutas:` | Repetir por cada elemento |
| Función | `def saludar(n): return "Hola " + n` | Receta reutilizable (`return` = lo que devuelve) |
| Errores | `try:` / `except:` | Intentá; si falla, hacé otra cosa |
| Importar | `import pandas as pd` | Traer herramientas (`as` = apodo) |
| APIs | `requests.get(url).json()` | Pedir datos a la web y convertirlos a dict |

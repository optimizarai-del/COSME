# Guía de preparación: Analytics and Modeling Senior Analyst (Accenture)

> **Nota crítica de postulación:** el CV debe enviarse 100% en inglés. Los filtros ATS (Applicant Tracking Systems) de esta línea de negocio global descartan automáticamente las aplicaciones con CV en español.

---

## Parte 1: Perfil del puesto, skills y requisitos

### Lenguajes de programación y consultas
- **SQL avanzado:** indispensable para transformaciones complejas, optimización de queries, JOINs avanzados y manejo de datos masivos en BigQuery.
- **Python:** scripts de automatización, limpieza de estructuras de datos complejas (pandas, numpy), manipulación de JSON y automatización de procesos.

### Automatización, orquestación e IA (foco principal)
- **n8n:** diseño y despliegue de flujos automatizados que conectan plataformas internas y herramientas del cliente.
- **Integración de LLMs:** incorporar modelos de lenguaje dentro de las automatizaciones de negocio.
- **APIs y mensajería:** APIs REST y GraphQL, autenticación, webhooks y colas de eventos (RabbitMQ, Pulsar).

### Pipelines y visualización de datos
- **Data pipelines (ETL):** construcción de pipelines con Dataflow / Apache Beam.
- **Business Intelligence:** tableros interactivos e insights accionables en Looker Studio o Tableau para Biz Ops Leads.

### Habilidades blandas
- **Debugging metódico:** alta tolerancia a la ambigüedad; resolver errores complejos en código y en flujos visuales.
- **Comunicación técnica efectiva:** traducir métricas complejas a lenguaje de negocio para líderes operativos.

## Parte 2: Ruta de estudio (8 semanas)

| Semanas | Tema | Objetivo | Materiales |
|---|---|---|---|
| 1–2 | SQL avanzado y BigQuery | Funciones analíticas, subconsultas complejas, optimización en la nube | Google Cloud Skills Boost ("BigQuery para Análisis de Datos"); Kaggle Advanced SQL (window functions, optimización) |
| 3–4 | Python para datos y APIs | Estructuras de datos complejas y consumo de servicios web | W3Schools Python (JSON + `requests`); freeCodeCamp *Python for Everybody* |
| 5–6 | n8n e IA integrada | Integraciones basadas en eventos y LLMs vía API | **n8n Academy** (Beginner + Intermediate, clave para la vacante); DeepLearning.AI *ChatGPT Prompt Engineering for Developers* |
| 7–8 | Pipelines y Data Viz | Arquitectura de datos y tableros con impacto de negocio | Looker Studio Help Center (reportes ejecutivos); Apache Beam docs (batch y streaming) |

### Checklist de progreso
- [ ] Semana 1 – SQL: window functions, CTEs, JOINs avanzados
- [ ] Semana 2 – BigQuery: particionado, clustering, optimización de costos
- [ ] Semana 3 – Python: pandas / numpy, limpieza de datos, JSON
- [ ] Semana 4 – APIs: `requests`, autenticación, REST vs GraphQL, webhooks
- [ ] Semana 5 – n8n Beginner
- [ ] Semana 6 – n8n Intermediate + integración de LLMs + colas (RabbitMQ/Pulsar)
- [ ] Semana 7 – Dataflow / Apache Beam (batch y streaming)
- [ ] Semana 8 – Looker Studio / Tableau: dashboard de KPIs de punta a punta
